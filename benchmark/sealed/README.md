# Sealed: benchmark ground truth. Don't open until the manual trials are done.

`catalog.b64` maps each opaque fault id to its recipe parameters and its label
(category, accepted alternatives, root cause). It is base64-encoded JSON so that a grep,
an IDE search or a quick look doesn't reveal it. It is not encrypted.

- Generated by `make benchmark-catalog` (seeded; `CHECK=1` verifies the file equals a
  fresh draw). Never edit it by hand.
- Nothing the diagnosis agent reads is derived from it: scenario builds use only the
  recipe, and every build scans bronze and the incidents table for fault ids, template
  keys and root-cause text (`benchmark/harness/leaks.py`).
- The manual trial shows one label at a time, after your diagnosis is saved.
